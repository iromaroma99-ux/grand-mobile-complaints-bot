# GRND Mobile — Telegram-бот для модерации жалоб

Бот опрашивает админ-панель сайта [grnd.gg](https://grnd.gg) (Grand Mobile RP), присылает новые жалобы в Telegram-группу и позволяет закрывать их прямо из Telegram — без захода на сайт.

## Возможности

- Автопроверка новых жалоб каждые N минут, с картинками и полным описанием
- Закрытие жалобы прямо из Telegram: свободный текст вердикта или быстрый выбор наказания (Warn/Mute/Jail/Ban + комбинации)
- Бейдж "админ" рядом с ником, если человек есть в списке админов сервера
- Автогенерация игровой команды (`/Offban`, `/offmute` и т.д.) для копирования после закрытия
- Отслеживание, если жалобу закрыл кто-то другой (не через бота) — сообщение в группе обновляется само
- `/pending` — список всех текущих нерешённых жалоб одним сообщением, с прямыми ссылками
- Почасовой автопостинг списка висящих жалоб
- `/status`, `/check`, `/stop` — статус, принудительная проверка, остановка мониторинга

## Как это устроено

Сайт grnd.gg не имеет официального публичного API — бот использует те же внутренние эндпоинты, что и сама админ-панель, полученные через DevTools браузера (вкладка Network при использовании сайта). Если домен/структура сайта изменится, эндпоинты могут потребовать повторного снятия через DevTools.

## Установка

1. **Python 3.10+**, затем:
   ```bash
   pip install pyTelegramBotAPI requests
   ```

2. **Создай Telegram-бота** через [@BotFather](https://t.me/BotFather), получи токен.

3. **Узнай свой Telegram ID** через [@userinfobot](https://t.me/userinfobot).

4. **Создай Telegram-группу**, добавь туда бота, дай ему права администратора (минимум — удаление сообщений, если хочешь автоудаление команд). Узнай ID группы через [@RawDataBot](https://t.me/RawDataBot) (добавь его в группу, напиши что-нибудь, посмотри `chat.id` в JSON-ответе — для супергрупп это отрицательное число вида `-100...`).

5. **Достань куку `grnd_sid`**:
   - Открой `grnd.gg` в браузере, залогинься под своим админ-аккаунтом
   - Открой DevTools → вкладка **Network** → зайди в раздел с жалобами
   - Найди любой запрос к `api-site.grnd.gg` → вкладка **Headers** → **Request Headers** → **Cookie**
   - Скопируй значение `grnd_sid` (оно начинается с `s%3A...`)
   - ⚠️ Эта кука — твоя рабочая сессия на сайте. Никому её не передавай, храни только в своих переменных окружения.

6. **Узнай номер своего сервера и регион** — видно в адресной строке сайта или в фильтрах админки (например, регион `ru`, сервер `33`).

7. **Задай переменные окружения**:
   ```bash
   export BOT_TOKEN="токен_от_botfather"
   export GRND_SID="s%3A...твоя_кука..."
   export ADMIN_ID="твой_telegram_id"
   export GROUP_CHAT_ID="-100...id_группы"
   export REGION="ru"
   export SERVER_ID="33"
   export ADMIN_TAG="ТвойНик"
   ```

8. **Запусти**:
   ```bash
   python bot.py
   ```

9. В Telegram напиши боту `/start` — он проверит текущие жалобы и начнёт мониторинг.

## Важно про куку

`grnd_sid` — это сессия сайта, она может протухать (обычно через несколько дней/недель). Если бот начнёт получать ошибки 403/404 при обращении к сайту — зайди на сайт заново, возьми свежую куку через DevTools (шаг 5) и обнови переменную окружения `GRND_SID`, затем перезапусти бота.

## Безопасность

- Закрытие жалоб доступно **только** тому, чей `ADMIN_ID` указан в переменных окружения.
- Никогда не публикуй свой `BOT_TOKEN` или `GRND_SID` — в т.ч. не коммить их в git. Используй переменные окружения или `.env`-файл, добавленный в `.gitignore`.
- Если решишь дать доступ ещё кому-то — им нужен **свой собственный** `grnd_sid` с правами на сервере; бот в текущем виде поддерживает только одного админа для закрытия жалоб.

## Адаптация под другой сервер/игру

Константы `PUNISHMENT_LABELS`, `PUNISHMENT_DURATIONS`, `OFF_COMMANDS` в начале `bot.py` — под конкретный сервер (код правил, названия команд наказаний). Поправь под свои нужды.

## Лицензия

Делай с этим кодом что хочешь. Используй на свой страх и риск — это неофициальный инструмент, использующий непубличные эндпоинты сайта.
